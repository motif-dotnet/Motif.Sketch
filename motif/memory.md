Rules for anyone working on the Motif.Sketch repo, on top of the [README](README.md), the [glossary](glossary.md) and [decisions.md](../decisions.md).

### Hard Rules
- The specs drive the app through its User port, so they can't see the page's layout. The browser specs (`Checks/Motif.Sketch.BrowserSpecs`) do: `TheAppBar` checks the app bar at 375 px (phone), 637 px (between the phone and narrow breakpoints) and 1280 px, in each mode it shows: the Example (`#example`), a repo link (`#repo=owner/name`), a snapshot link, and the visitor's own work. The bar passes when its content is no wider than the bar (`scrollWidth <= clientWidth`) and nothing overlaps. `TheBanners` checks the banner under the bar the same way, in each mode that shows one. After a change to the bar, a banner or anything else the layout depends on, run them, and add a case for any new mode or banner. Anything else on screen still gets the same check by hand in a browser, at those widths and in those modes.
- `Suite/`, `wwwroot/css/motif.css`, `wwwroot/fonts/` and `scripts/sync-suite.sh` are the Motif web kit's copy. Change the kit in motif-dotnet/.github (`brand/web`), push it, then sync it here with `scripts/sync-suite.sh`. Never edit the copy.
